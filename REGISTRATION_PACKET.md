# Registration Packet

## Upwork Title

Client Portal & Admin API for Service Teams

## Role

Full-Stack Developer

## Description To Paste

Sample project: I built a full-stack client portal and admin dashboard for small service teams. The app tracks client accounts, active requests, invoice status, owner workload, SLA risk, and recent API activity. It includes a responsive dashboard, request creation flow, generated operations handoff, JSON report export, and a local Node.js REST API server with routes for clients, requests, invoices, and summary metrics. Live demo and GitHub repository are included.
