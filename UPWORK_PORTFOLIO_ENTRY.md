## Long Description

This is a sample project built to demonstrate full-stack web app development for small service businesses and agencies.

The dashboard helps a team manage client accounts, active requests, invoice status, SLA risk, owner workload, and recent activity from one place. It includes a working admin interface, generated handoff summary, JSON report export, and a local Node REST API server with routes for clients, requests, invoices, and summary metrics.

The goal was to show how I would structure a practical internal tool: start with a clear workflow, define the data model, build a usable admin UI, and expose clean API routes that can later connect to a database, authentication, payment system, CRM, or email automation.

Key features:
- Client account health dashboard
- Request queue with filters and completion actions
- Revenue, SLA risk, owner workload, and invoice metrics
- Admin form for creating new requests
- Generated operations handoff
- JSON report export
- Node.js REST API server
- API routes for clients, requests, invoices, and summary data
- Responsive interface for desktop and mobile review

Built with HTML, CSS, JavaScript, and Node.js. The public demo runs with sample data, while the GitHub repository includes the local API server code.
